Objective
Generate thematic EU5 advances for countries listed in %{file_name}.txt, using %{EU5 Advances} as the reference standard.

Input analysis
1. Review %{EU5 Advances} to learn:
- Standard advance block structure
- Commonly used EU5 modifier types
- Valid requires references
- Relevant icon values

2. Read %{file_name}.txt to identify:
- Country names
- Country tags
- The intended thematic direction for each country

Core output rules
1. Each country must have exactly 9 advances, distributed as:
- Age 1: 2 advances
- Age 2: 2 advances
- Age 3: 2 advances
- Age 4: 2 advances
- Age 5: 1 advance
- Age 6: 1 advance

2. Naming format for all advances:
- abm_<ideas_name>_tradition_(1|2) # traditions
- abm_<advance_name> # regular advances
- abm_<ideas_name>_ambition #ambition

3. Field rules:
- requires must reference a valid existing advance from %{EU5 Advances}
- icon must be a relevant value present in %{EU5 Advances}

4. Modifier rules:
- Modifier keys should be unique per tag and not overrepresented within the same regional file
- Do not use direct military quality modifiers such as discipline or army_morale_modifier
- Prefer socioeconomic, governmental, trade, production, and related non-direct-combat effects

Ordering and completeness rules
1. Advances must be ordered by age from 1 to 6.
2. For idea-based imports, preserve the original idea order while assigning ages.
3. For standalone country sets in existing files, if age 6 is missing, add exactly one meaningful and properly themed age 6 advance to complete the 9-advance structure.

EU4 import rule
For countries imported from EU4 ideas, convert EU4 effects into appropriate EU5 equivalents while preserving original idea intent.

Output expectation
For each country, output valid advance blocks that satisfy all naming, age distribution, ordering, field, and modifier rules above.
