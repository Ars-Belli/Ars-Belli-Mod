# Generate EU5 advance definitions from EU4 national idea sets for `eu5_tag` rows
# with fewer than 10 generated ABM advances.
#
# Sources:
# - Tag / country data: `.tools/india_merged.csv`
# - EU4 national ideas: `.tools/eu4/ideas/*.txt`
#
# General rules:
# - Ignore EU4 `trigger` blocks completely.
# - Do not use EU4 `trigger` blocks to determine applicable tags.
# - Use the tag list in the source comment immediately above each idea set as the
#   authoritative tag mapping.
# - Do not generate an idea set again if all of its relevant tags already have
#   10 or more generated ABM advances.
#
# EU4 idea-set structure:
# - Every processed EU4 idea set has:
#   - 2 traditions from `start`
#   - 7 regular ideas
#   - 1 ambition / bonus from `bonus`
# - Generate 10 advances per normal idea set:
#   - Age 1: tradition 1 and tradition 2
#   - Age 2: idea 1 and idea 2
#   - Age 3: idea 3 and idea 4
#   - Age 4: idea 5 and idea 6
#   - Age 5: idea 7
#   - Age 6: ambition / bonus
#
# Age values:
# - Traditions: `age = age_1_traditions`
# - Ideas 1 and 2: `age = age_2_renaissance`
# - Ideas 3 and 4: `age = age_3_discovery`
# - Ideas 5 and 6: `age = age_4_reformation`
# - Idea 7: `age = age_5_absolutism`
# - Ambition: `age = age_6_revolutions`
#
# Naming conventions:
# - Tradition 1: `abm_<idea_set>_tradition_1`
# - Tradition 2: `abm_<idea_set>_tradition_2`
# - Normal regular idea: `abm_<idea_name>`
# - Ambition: `abm_<idea_set>_ambition`
#
# Example:
# - `sumatran_ideas` tradition 1:
#   `abm_sumatran_ideas_tradition_1`
# - `reliance_on_trade`:
#   `abm_reliance_on_trade`
# - `sumatran_ideas` ambition:
#   `abm_sumatran_ideas_ambition`
#
# Potential block rules:
# - Every advance must have a `potential` block.
# - Use `has_or_had_tag` for every tag.
# - If exactly one tag uses the advance, do not use an `OR` block:
#
#   potential = {
#       has_or_had_tag = <TAG>
#   }
#
# - If two or more tags use the advance, use one `OR` block:
#
#   potential = {
#       OR = {
#           has_or_had_tag = <TAG_1>
#           has_or_had_tag = <TAG_2>
#       }
#   }
#
# Requirements:
# - Every advance must include one `requires = <advance_key>` entry.
# - `requires` is a single advance key, never a list.
# - Use an existing advance key when an appropriate prerequisite is known.
# - Select prerequisites based on the advance's primary theme where possible.
# - Do not require that advances form a linear chain within the EU4 idea set.
# - Do not use display names in `requires`.
# - If an appropriate prerequisite is unknown, use a descriptive placeholder:
#
#   requires = TODO_<theme>_requirement
#
# - Examples:
#   - `TODO_trade_efficiency_requirement`
#   - `TODO_naval_morale_requirement`
#   - `TODO_missionary_strength_requirement`
#   - `TODO_fortifications_requirement`
#
# Modifier preservation:
# - Preserve every original EU4 modifier as a comment directly inside the
#   generated advance.
# - Preserve modifier keys and values exactly as written in the source.
# - Preserve source spelling errors exactly, including keys such as:
#   - `sailor_maintenance_modifer`
#   - `leader_naval_manuever`
#   - `sunk_ship_morale_hit_recieved`
# - Do not remove, merge, reinterpret, round, correct, or silently discard
#   EU4 modifiers.
#
# Tradition conversion:
# - The two modifiers in an EU4 `start` block become two separate advances:
#   - The first modifier becomes tradition 1.
#   - The second modifier becomes tradition 2.
#
# Ambition conversion:
# - The modifier or modifiers in the EU4 `bonus` block become one ambition
#   advance for Age 6.
#
# Duplicate regular-idea rules:
# - Do not automatically treat identical idea names as shared advances.
# - An identical idea key is shared only when the EU4 source explicitly says so,
#   for example:
#
#   settle_the_islands = { # same as malay ideas
#       global_colonial_growth = 20
#   }
#
# - Explicitly shared ideas produce one common advance using:
#
#   abm_<idea_name>
#
# - Merge the tags of every explicitly shared occurrence into that advance's
#   `potential` block.
# - If the shared source modifiers are identical, preserve them only once.
# - If a shared idea appears at different positions in different idea sets and
#   therefore has conflicting ages or requirements, use placeholders:
#
#   age = TODO_shared_<idea_name>_age
#   requires = TODO_shared_<idea_name>_requirement
#
# - Do not generate duplicate definitions of an explicitly shared advance.
#
# Conflicting duplicate-name rules:
# - If the same EU4 idea key appears in multiple idea sets without an explicit
#   shared-idea annotation, treat the occurrences as separate advances.
# - This is especially required when their modifiers differ.
# - Namespace each conflicting advance by its source idea set:
#
#   abm_<idea_set>_<idea_name>
#
# - Example:
#
#   # Sumatran version:
#   porch_of_mecca = {
#       global_missionary_strength = 0.02
#   }
#
#   # Aceh version:
#   porch_of_mecca = {
#       technology_cost = -0.10
#   }
#
#   # Generated keys:
#   abm_sumatran_ideas_porch_of_mecca
#   abm_atj_ideas_porch_of_mecca
#
# Output format:
# - Add a comment header with the idea-set display name.
# - Add a comment listing every applicable tag.
# - Use Paradox script formatting and project indentation.
# - Follow the existing file convention regarding `icon`.
# - If icons are required but no suitable icon is known, use:
#
#   icon = TODO_<theme>_icon
#
# - Do not generate duplicate advance keys unless they are intentionally
#   namespaced conflicting versions of the same EU4 idea name.
#
# Standard structure:
#
# # <Idea Set Display Name>
# # <TAG_1> <TAG_2>
#
# <advance_key> = {
#     age = <age_key>
#     potential = {
#         OR = {
#             has_or_had_tag = <TAG_1>
#             has_or_had_tag = <TAG_2>
#         }
#     }
#
#     requires = <prerequisite_advance>
#
#     # <original_eu4_modifier> = <original_value>
# }
