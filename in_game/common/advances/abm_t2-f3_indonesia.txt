# Generate EU5 advance definitions from EU4 national idea sets for `eu5_tag` rows
# with fewer than 10 generated ABM advances.
#
# Sources:
# - Tag / country data: `.tools/india_merged.csv`
# - EU4 national ideas: `.tools/eu4/ideas/*.txt`
#
# General rules:
# - Ignore EU4 `trigger` blocks completely.
# - Do not use EU4 `trigger` blocks to determine applicable tags.
# - Use the tag list in the source comment immediately above each idea set as the
#   authoritative tag mapping.
# - Do not generate an idea set again if all of its relevant tags already have
#   10 or more generated ABM advances.
#
# EU4 idea-set structure:
# - Every processed EU4 idea set contains:
#   - 2 traditions in `start`
#   - 7 regular ideas
#   - 1 ambition / bonus in `bonus`
# - Generate 10 advances per normal idea set:
#   - Age 1: tradition 1 and tradition 2
#   - Age 2: regular idea 1 and regular idea 2
#   - Age 3: regular idea 3 and regular idea 4
#   - Age 4: regular idea 5 and regular idea 6
#   - Age 5: regular idea 7
#   - Age 6: ambition / bonus
#
# Age values:
# - Traditions:
#   `age = age_1_traditions`
# - Regular ideas 1 and 2:
#   `age = age_2_renaissance`
# - Regular ideas 3 and 4:
#   `age = age_3_discovery`
# - Regular ideas 5 and 6:
#   `age = age_4_reformation`
# - Regular idea 7:
#   `age = age_5_absolutism`
# - Ambition:
#   `age = age_6_revolutions`
#
# Naming conventions:
# - Tradition 1:
#   `abm_<idea_set>_tradition_1`
# - Tradition 2:
#   `abm_<idea_set>_tradition_2`
# - Normal regular idea:
#   `abm_<idea_name>`
# - Ambition:
#   `abm_<idea_set>_ambition`
#
# Example naming:
# - First Sumatran tradition:
#   `abm_sumatran_ideas_tradition_1`
# - Sumatran idea `reliance_on_trade`:
#   `abm_reliance_on_trade`
# - Sumatran ambition:
#   `abm_sumatran_ideas_ambition`
#
# Potential block rules:
# - Every advance must include a `potential` block.
# - Use `has_or_had_tag` for every tag.
# - If exactly one tag uses an advance, do not use an `OR` block:
#
#   potential = {
#       has_or_had_tag = <TAG>
#   }
#
# - If two or more tags use an advance, place all tags in a single `OR` block:
#
#   potential = {
#       OR = {
#           has_or_had_tag = <TAG_1>
#           has_or_had_tag = <TAG_2>
#       }
#   }
#
# Requirements:
# - Every advance must include exactly one `requires = <advance_key>` entry.
# - `requires` is a single advance key, never a list.
# - Never use display names in `requires`.
# - Select an existing prerequisite advance that best matches the primary theme
#   of the generated advance, when one is known.
# - Advances do not need to form a linear prerequisite chain within their
#   original EU4 idea set.
# - If no suitable existing prerequisite is known, use a descriptive placeholder:
#
#   requires = TODO_<theme>_requirement
#
# - Examples:
#   `requires = TODO_trade_efficiency_requirement`
#   `requires = TODO_naval_morale_requirement`
#   `requires = TODO_missionary_strength_requirement`
#   `requires = TODO_fortifications_requirement`
#   `requires = TODO_diplomatic_reputation_requirement`
#
# Icons:
# - Every generated advance must include an `icon` key.
# - Select an existing project icon key that best matches the advance's primary
#   theme, source idea name, or most important modifier.
# - Prefer existing project icon keys; do not invent new icon keys unless the
#   project explicitly supports creating them.
# - If no suitable existing icon can be identified, use a descriptive placeholder:
#
#   icon = TODO_<theme>_icon
#
# - Suggested placeholder themes:
#   - Trade, merchants, trade power, trade efficiency, trade steering:
#     `icon = TODO_trade_icon`
#   - Ships, sailors, naval morale, naval force limit, ship cost:
#     `icon = TODO_naval_icon`
#   - Land morale, infantry, manpower, warfare, attrition:
#     `icon = TODO_military_icon`
#   - Missionaries, religious conversion, tolerance:
#     `icon = TODO_religion_icon`
#   - Technology, institutions, advisors, idea cost, scholarship:
#     `icon = TODO_scholarship_icon`
#   - Prestige, legitimacy, stability, authority, government:
#     `icon = TODO_government_icon`
#   - Production, tax, trade goods, construction, development:
#     `icon = TODO_economy_icon`
#   - Diplomacy, diplomats, reputation, relations:
#     `icon = TODO_diplomacy_icon`
#   - Colonization, settlers, colonial growth:
#     `icon = TODO_colonization_icon`
#   - Forts, defensiveness, defensive structures:
#     `icon = TODO_fortification_icon`
# - Traditions may use their own advance key as the icon only when the icon
#   already exists in the project:
#
#   icon = abm_<idea_set>_tradition_1
#
# Modifier preservation:
# - Preserve every original EU4 modifier as a comment directly inside the
#   generated advance.
# - Preserve modifier keys and values exactly as written in the EU4 source.
# - Do not remove, merge, reinterpret, round, correct, or silently discard
#   EU4 modifiers.
# - Preserve source spelling errors exactly, including modifier keys such as:
#   - `sailor_maintenance_modifer`
#   - `leader_naval_manuever`
#   - `sunk_ship_morale_hit_recieved`
#
# Tradition conversion:
# - The two modifiers in the EU4 idea set's `start` block become two separate
#   Age 1 tradition advances.
# - The first modifier becomes tradition 1.
# - The second modifier becomes tradition 2.
#
# Ambition conversion:
# - The modifier or modifiers in the EU4 idea set's `bonus` block become one
#   Age 6 ambition advance.
#
# Explicitly shared regular ideas:
# - Do not automatically treat identical idea names as shared advances.
# - A regular idea is shared only when the EU4 source explicitly identifies it
#   as shared, for example:
#
#   settle_the_islands = { # same as malay ideas
#       global_colonial_growth = 20
#   }
#
# - An explicitly shared idea produces one shared advance:
#
#   abm_<idea_name>
#
# - Merge all tags from every explicitly shared occurrence into the shared
#   advance's `potential` block.
# - If the source modifier blocks are identical, preserve the modifier comments
#   only once in the shared advance.
# - Use one icon that matches the shared advance's common effect or theme.
# - If the shared advance occurs at different positions in different idea sets,
#   and therefore has conflicting ages or prerequisites, use placeholders:
#
#   age = TODO_shared_<idea_name>_age
#   requires = TODO_shared_<idea_name>_requirement
#
# - Generate the shared advance only once.
#
# Conflicting duplicate regular-idea names:
# - If the same EU4 idea key appears in multiple idea sets without an explicit
#   shared-idea annotation, treat each occurrence as a separate advance.
# - This is required even if the names are identical, especially when modifiers
#   differ.
# - Namespace each conflicting advance using its source idea set:
#
#   abm_<idea_set>_<idea_name>
#
# - Example:
#
#   # Sumatran version:
#   porch_of_mecca = {
#       global_missionary_strength = 0.02
#   }
#
#   # Aceh version:
#   porch_of_mecca = {
#       technology_cost = -0.10
#   }
#
#   # Generated advances:
#   abm_sumatran_ideas_porch_of_mecca
#   abm_atj_ideas_porch_of_mecca
#
# - Each namespaced conflicting advance receives only the tags, age, icon,
#   requirement, and modifier comments belonging to its own source idea set.
#
# Output formatting:
# - Add a comment header containing the idea-set display name.
# - Add a comment listing all tags applicable to that idea set or advance.
# - Follow the project's established Paradox script indentation and formatting.
# - Do not generate duplicate advance keys.
# - The exception is conflicting duplicate EU4 idea names, which must be
#   namespace-qualified as described above.
#
# Standard output structure:
#
# # <Idea Set Display Name>
# # <TAG_1> <TAG_2>
#
# <advance_key> = {
#     age = <age_key>
#     icon = <existing_icon_key_or_TODO_placeholder>
#     potential = {
#         OR = {
#             has_or_had_tag = <TAG_1>
#             has_or_had_tag = <TAG_2>
#         }
#     }
#
#     requires = <prerequisite_advance>
#
#     # <original_eu4_modifier> = <original_value>
# }
#
# Single-tag example:
#
# abm_example_advance = {
#     age = age_2_renaissance
#     icon = TODO_trade_icon
#     potential = {
#         has_or_had_tag = EXM
#     }
#
#     requires = TODO_trade_requirement
#
#     # trade_efficiency = 0.10
# }
#
# Multi-tag example:
#
# abm_example_advance = {
#     age = age_2_renaissance
#     icon = TODO_trade_icon
#     potential = {
#         OR = {
#             has_or_had_tag = EXM
#             has_or_had_tag = EX2
#         }
#     }
#
#     requires = TODO_trade_requirement
#
#     # trade_efficiency = 0.10
# }
