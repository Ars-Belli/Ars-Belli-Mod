# Ars Belli - upkeep for the governor-office buildings and the Proconsulate.
# no_upkeep mirrors vanilla cardinal_maintenance (unsorted_building_inputs.txt:65).
#
# One production method per building, so the upkeep slot shows that building's own icon
# (icon_type = building_type + icon = the building's own key, resolved from
# gfx/interface/icons/buildings). abm_governor_offices_maintenance is kept only so that
# saves made before the split still resolve a valid upkeep method - no building uses it.
