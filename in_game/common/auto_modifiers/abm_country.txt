# Ars Belli - governor offices (building_types/abm_governor_offices.txt).
#
# No levels any more: one office per LOCATION (max_levels = 1, and the engine allows only
# one instance of a building type per location), unlimited copies per country, each one
# eating one governor post through the building's own allow gate. The reward therefore
# scales with the NUMBER of completed offices, not with levels: one auto modifier per
# step, keyed on has_building + count. has_building sees completed buildings only, so
# starting construction does not hand the slot out early
# (total_building_levels_including_construction would).
#
# The ladder stops at 4 because that is as many offices as the posts allow: the local cap
# tops out at 4 (base 1 + kingdom/empire + local_governor_advance +
# power_projection_advance_5) and the naval cap at 4 (maritime_advance_age_3,
# harbor_administration, naval_infrastructure_act, thalassocracy). Add a step if a new
# source raises either cap.

# Provincial Chancellery: one office held.
abm_provincial_chancellery_1 = {
	potential_trigger = {
		any_owned_location = {
			has_building = building_type:abm_provincial_chancellery
		}
	}
	num_local_governors = -1
	government_reform_slots = 1
}
